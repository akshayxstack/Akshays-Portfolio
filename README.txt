Akshay portfolio - static site (no install, no build)

Files: index.html (Home + Contact), about.html, skills.html (Skills & Projects),
journey.html (Education, Experience, Certs), fonts/, assets/, js/, Akshay_Resume.pdf

Preview: open index.html (or run `python3 -m http.server` in this folder).
Deploy: drag this whole folder onto Vercel / Netlify / Cloudflare Pages / GitHub Pages.

To update later:
- LinkedIn link: search for linkedin.com/akshay in index.html and replace with your real URL (2 places).
- CV: replace Akshay_Resume.pdf with your latest file (same name).
